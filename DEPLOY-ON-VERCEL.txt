METHOD A — easiest if you have a GitHub account (no Terminal)
-------------------------------------------------------------
1. Unzip this file. You should see package.json inside the folder
   (not another nested zip).
2. Go to https://github.com/new
   - Repository name: mums-night-out
   - Private
   - Create repository
3. On the empty repo page, click "uploading an existing file"
   (or Add file → Upload files).
4. Drag EVERYTHING inside the unzipped folder onto GitHub
   (package.json, src, public, …). Click Commit changes.
5. Go to https://vercel.com/login and sign in.
6. Switch to the team "mml-guide" (top-left).
7. Open the existing project:
   https://vercel.com/mml-guide/mums-night-out
8. Settings → Git → Connect Git Repository → choose the GitHub
   repo you just created. Confirm it deploys the root folder
   (where package.json is). Framework: Next.js.
9. Deployments → click Deploy / Redeploy production.
10. Open https://mums-night-out.vercel.app and hard-refresh.


METHOD B — Terminal on your laptop (most reliable)
--------------------------------------------------
1. Unzip this file.
2. Install Node.js LTS from https://nodejs.org if you do not have it.
3. Open Terminal and go into the unzipped folder, for example:

     cd ~/Downloads/mums-night-out-vercel-upload

   You must be in the folder that contains package.json.

4. Log in to Vercel in the browser:

     npx vercel login

5. Deploy to the existing production project:

     npx vercel deploy --prod --yes --scope mml-guide

   This folder already contains .vercel/project.json pointing at
   project mums-night-out, so it should not create a new site.

6. When it finishes, open https://mums-night-out.vercel.app
